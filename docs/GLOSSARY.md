# Zerpa Canonical Glossary

| Term | Meaning |
|------|---------|
| **Organization** | Legal or holding entity that may contain one or more companies |
| **Company** | Operating tenant / workspace; primary isolation unit |
| **Location / Branch** | Physical or logical site under a company |
| **Membership** | User ↔ company link with role and permissions |
| **Vertical Pack** | Installable industry configuration (nav, labels, roles, workflows, skills) |
| **Work Item** | Generic operational record; labeled Tickets, Cases, Bookings, Job Cards, etc. |
| **Account / Customer** | Party a company sells to or serves |
| **Contact** | Person linked to an account or work item |
| **Agreement / Contract** | Recurring commercial relationship (e.g. MSP managed service) |
| **Nest** | Guided launch/onboarding checklist from sale to go-live |
| **SLA** | Service level agreement clock and target |
| **RICA** | South African subscriber identity verification for telecom |
| **Provisioning** | Activating a telecom/ISP service end-to-end |
| **Outbox Event** | Transactional event written with domain data for async processing |
| **Zerpa Assist** | Tenant-scoped copilot with approval-gated actions |
| **Platform Admin** | Zerpa HQ staff operating the multi-tenant platform |

## Canonical Vertical IDs
`MSP` · `TELECOM` · `FUNERAL` · `SPA` · `RESTAURANT` · `AUTOMOTIVE` · `GENERIC`

Deprecated aliases: `AUTO` → `AUTOMOTIVE`, `TECH` → prefer `MSP` or `GENERIC`.
